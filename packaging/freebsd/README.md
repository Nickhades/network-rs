# FreeBSD packaging

**Languages:** [English](README.md) | [简体中文](README.zh-CN.md)

This directory contains the deployment artifacts and a port skeleton for
nm-freebsd.

## Layout

- etc/dbus-1/system.d/org.freedesktop.NetworkManager.conf: system bus policy.
- etc/dbus-1/system-services/org.freedesktop.NetworkManager.service.in: D-Bus activation.
- etc/rc.d/nm_freebsd: rc.d script.
- ports/net-mgmt/nm-freebsd: port skeleton. cargo-crates.mk is generated from
  the workspace Cargo.lock.

## One-click install

From the repository root, as root:

```sh
sudo scripts/install.sh
```

This checks dependencies, builds the daemon (and plugin by default on a host
with GTK/XFCE development libraries), installs the policy, activation service,
rc.d script and plugin, enables and starts the service, reloads D-Bus and runs
the smoke test. Use `--no-plugin`, `--no-start`, `--destdir` or
`--install-deps` as needed; see `scripts/install.sh --help`.

The installer uses the files in this directory, so a packaged system and a
source install stay consistent.

## Installing the port skeleton

Copy ports/net-mgmt/nm-freebsd to a ports tree as net-mgmt/nm-freebsd, set
MAINTAINER to a real address (GH_ACCOUNT already points at Nickhades), then run:

    make makesum
    make install clean

CARGO_CRATES is generated by tools/gen-port-crates.py. Re-run it after any
Cargo.lock change:

    python3 tools/gen-port-crates.py > packaging/freebsd/ports/net-mgmt/nm-freebsd/cargo-crates.mk

## Manual install (development)

Build the daemon and (optionally) the plugin:

    cargo build --release -p nm-freebsd-daemon
    cargo build --release -p nm-xfce-plugin

Install as root:

    install -m 755 target/release/nm-freebsd-daemon /usr/local/bin/
    install -d /usr/local/etc/dbus-1/system.d /usr/local/share/dbus-1/system-services
    install -m 644 packaging/freebsd/etc/dbus-1/system.d/org.freedesktop.NetworkManager.conf /usr/local/etc/dbus-1/system.d/
    sed 's|%%PREFIX%%|/usr/local|g' packaging/freebsd/etc/dbus-1/system-services/org.freedesktop.NetworkManager.service \
        > /usr/local/share/dbus-1/system-services/org.freedesktop.NetworkManager.service
    sed 's|%%PREFIX%%|/usr/local|g' packaging/freebsd/etc/rc.d/nm_freebsd > /usr/local/etc/rc.d/nm_freebsd
    chmod 755 /usr/local/etc/rc.d/nm_freebsd
    install -d /usr/local/lib/xfce4/panel/plugins /usr/local/share/xfce4/panel/plugins
    install -m 755 target/release/libnm_freebsd_xfce.so /usr/local/lib/xfce4/panel/plugins/
    install -m 644 target/release/build/nm-xfce-plugin-*/out/nm_freebsd_xfce.desktop /usr/local/share/xfce4/panel/plugins/

Then reload the bus so it reads the new policy:

    service dbus restart
    sysrc nm_freebsd_enable=YES
    service nm_freebsd start

## Access control

The D-Bus policy grants full control only to root and members of `wheel` or
`network`; other local users get read-only calls. Add the desktop user to
`network` if they are not in `wheel`:

    pw groupmod network -m <user>

Log out and back in afterwards. Do not install this MVP on a multi-user or
hostile-local-user machine until polkit/SecretAgent support lands. Saved PSKs
are in `/var/db/nm-freebsd/keyring.json` (0600) but are not encrypted at rest.

## Notes

- The daemon must run as root: wpa_supplicant's control socket is root:wheel
  with mode 0770.
- Stock FreeBSD wpa_supplicant has no D-Bus interface, so the default
  auto backend uses the control socket.
- The XFCE plugin is an optional port component (OPTIONS XFCE, off by default).
  Enable it with "make config" or "make -DWITH_XFCE=yes install clean" on
  XFCE systems; headless builders need not install GTK/XFCE.
